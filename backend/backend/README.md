# Overview

Dental Healthcare Management System เป็นระบบบริหารจัดการงานทันตกรรมและบริการสุขภาพ

ออกแบบสำหรับรองรับ:

- Flutter Mobile Application
- Flutter Web Admin
- REST API
- Healthcare Integration
- Notification System
- Appointment Management
