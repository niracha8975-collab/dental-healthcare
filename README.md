# Dental Healthcare Management System

> Production-Ready Digital Dental Healthcare Platform for
> **Rai Lak Thong Subdistrict Health Promoting Hospital (RHPH)**
> Chonburi Province, Thailand

---

## Overview

Dental Healthcare Management System is an enterprise-grade healthcare platform designed to support dental services provided by Thai Subdistrict Health Promoting Hospitals (โรงพยาบาลส่งเสริมสุขภาพตำบล).

The system is built using modern technologies and follows Clean Architecture, SOLID principles, RESTful API standards, and Thai Ministry of Public Health interoperability requirements.

---

## Objectives

- Online dental appointment booking
- Patient registration
- Digital Dental EMR
- Tooth Chart
- Recall System
- Dental Health Promotion
- GIS Analysis
